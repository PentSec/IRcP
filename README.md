A Vencord theme that turns Discord into a terminal IRC client: one log line per message,
a clock gutter, monospace type, dim metadata and translucent panels over a wallpaper.

```
13:38 <PentSec> one line per message, with the clock, the nick and the text
13:38 <PentSec> sharing a single baseline
```

## Requirements

- [Vencord](https://vencord.dev) (or Vesktop) on Discord desktop.
- Optional: the **RoleColorEverywhere** plugin, if you want the member-list role headers
  painted with each role's own colour. Discord does not expose that colour otherwise.

## Install

### Online (recommended)

1. Open Discord → **Vencord → Settings → Themes**.
2. Paste this URL into **Online Themes**, one per line:

   ```
   https://jeff.is-a.dev/IRcP/irc.theme.css
   ```

3. Leave the field. The theme applies immediately.

> The theme is served by GitHub Pages (`.css` as `text/css`). Its imports point at the same
> deployment, so a downloaded `irc.theme.css` works on its own. Do not use
> `raw.githubusercontent.com`: it serves `.css` as `text/plain` with `nosniff`, and the
> browser refuses it as a stylesheet.

### Local

1. Download `irc.theme.css`. The single file is enough: its two imports point at the
   hosted body, so the layout loads from the same deployment.
2. Drop it into your Vencord themes directory (Vencord → Themes → _Open Themes Folder_).
3. Enable it in the **Local Themes** list.

To change the layout itself, do not edit the downloaded file — clone the repository and
use `bun run dev` (see below).

### Upgrading from 2.0.0-irc.57 or older

Those versions loaded their layout from `irc/01-status.css`, `irc/02-ui.css`,
`irc/03-fonts.css` and `irc/05-messages.css`. Those files are no longer published: the
layout now ships as `irc.css` and `fonts.css`. An old `irc.theme.css` left in place will
load the metadata and the variables but **no layout**. Delete it and install again.

## Development

The repository holds sources, not the built theme. `deploy` is generated by CI.

```bash
bun install          # once
bun run dev          # one self-contained irc.theme.css in your Vencord themes folder
bun run build        # dist/: irc.theme.css, irc.css, fonts.css, bg.png, .nojekyll
bun run reroll       # update Discord's hashed class names in src/**/_*.scss
bun run verify:cascade  # fail if a rule moved past a rule it can fight with
bun run format       # Prettier
```

`bun` is the only package manager used here; `bun.lock` is committed.

```
src/root.scss              metadata lives in bd-scss.config.js; this file is the variables
src/main.scss              body entry: @use order = cascade order
src/theme/_tokens.scss     internal custom properties shared by everything
src/theme/app/             background, titlebar, toolbar, window controls
src/theme/serverlist/      guild rail: folders, items, unread pill, icons
src/theme/sidebar/         channel and DM lists, user panel
src/theme/chat/            message area, composer, dividers, notices, mentions
src/theme/members/         member list: column, rows, role groups
src/theme/popouts/         server and channel popouts
src/theme/messages/        one-line rows: row, clock, runs, reply, nick, avatar
src/theme/forum/           forum posts as log lines
src/theme/status/          presence rings, glow, avatar exceptions
src/theme/_wiring.scss     maps --irc-font onto the variables Discord reads
src/addons/_fonts.scss     Iosevka subsets, base64 (separate file: 460 KB)
src/assets/bg.png          background, published next to the theme
scripts/postbuild.mjs      asset copy, deploy URL, @name, .nojekyll
scripts/dev.mjs            initial build + watcher (bd-scss skips the first one)
```

Each folder has an `index.scss` that `@forward`s its partials in cascade order. Adding a
file means adding its `@forward` in the right position: the order is the cascade, not
alphabetical.

`bun run dev` builds once and then rebuilds on every save: a single file with the fonts
and the body inlined, dropped in your client's themes folder
(`~/.config/Vencord/themes` on Linux; use it by enabling _Local Themes_). `bun run build`
splits it instead: the entry imports `irc.css` and `fonts.css` from the deployed URL.

The wrapper in `scripts/dev.mjs` exists because `bd-scss dev` starts the watcher but never
compiles on startup — it waits for the first file change.

## Configuration

Everything worth touching is in the `:root` block of `src/root.scss`, which compiles into
the top of `irc.theme.css`. Edit it, run the build, publish.

| Variable                                                  | What it does                                                      | Default             |
| --------------------------------------------------------- | ----------------------------------------------------------------- | ------------------- |
| `--accent`                                                | Theme colour: glows, mentions, categories, unread pills           | `hsl(164 100% 45%)` |
| `--glow-intensity`                                        | Strength of every glow; `0` disables them                         | `1`                 |
| `--background-image`                                      | Optional override for the wallpaper; must be an absolute URL      | _(unset)_           |
| `--background-blur`                                       | Blur applied to the background image                              | `8px`               |
| `--opacity`                                               | Opacity of the app panels                                         | `0.78`              |
| `--irc-line-height`                                       | Line height of a message row                                      | `1.25`              |
| `--irc-ts-width`                                          | Clock column width (`8ch` for a 12-hour clock, `5ch` for 24-hour) | `8ch`               |
| `--irc-avatar-size`                                       | Avatar box in a message row; above `1em` the row grows            | `1.2em`             |
| `--irc-nick-glow` / `--irc-nick-glow-size`                | Nickname halo strength and blur                                   | `1` / `6px`         |
| `--irc-forum-stamp`                                       | Width of the forum thumbnail column                               | `3.4em`             |
| `--irc-forum-row-pad`                                     | Vertical padding of a forum log row                               | `2px`               |
| `--irc-status-members-width`                              | Member-list avatar box the ring is drawn around                   | `30px`              |
| `--irc-status-self-speaking-colour`                       | Ring colour while your own voice transmits                        | `#57d39b`           |
| `--irc-status-*`                                          | Avatar ring sizes and colours                                     | see the file        |
| `--members-width`, `--guilds-width`, `--server-icon-size` | Sidebar geometry                                                  | see the file        |

Published changes reach clients without a restart: the entry file is re-fetched on a
theme toggle, and the body is a normal cached HTTP resource with a ten-minute lifetime.

## Notes

- The font (Iosevka Term Slab) is embedded as base64 subsets, so no font is fetched.
- Forum channels, the Friends tab and the member list are themed as well. Discord moves
  these class hashes between builds, so a layout touch-up may be needed after a large
  Discord update.
- The chat toolbar icons are Tabler outline icons drawn as CSS masks.
